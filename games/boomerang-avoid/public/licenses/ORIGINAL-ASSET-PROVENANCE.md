# BoomerangaVOID original asset provenance

This release uses the existing gamefeel cast: Pip, Volt, Kiln, Nori, Cairn and
Comet, under `models/gamefeel/`. These six characters were authored for this
project with a Python generator in the installed Blender 5.2 command-line tool.
Their geometry, materials, eight-bone rigs and twelve action clips are original
project work. The editable source, generator, hashes and validation records are
in `assets-src/boomerangavoid/gamefeel/` in the source repository.

The user-owned Little Weirdos QA images and character source were inspected as
read-only style references for soft forms, expressive mouthless faces and soft
appendages. No Little Weirdos source geometry, textures or gallery records were
copied. Blender MCP was unavailable; Blender CLI was used. Meshy, text-to-mesh,
paid generation providers and imported third-party character packs were not used.

Arenas, vegetation, weapons, particles and other scene effects are authored in
the game's Three.js renderer. Sound and music use project-authored Web Audio
synthesis. The game uses its own characters, arenas, audio and name; no assets
from Boomerang Fu are included.

The Comet model here is the previously accepted gamefeel model. The separate,
uncommitted Comet/presentation candidate and paused visual work are not included.

Third-party library and font notices are reproduced separately in
`THIRD-PARTY-NOTICES.txt`. This provenance note is factual documentation, not an
additional license grant or a claim of legal clearance.
