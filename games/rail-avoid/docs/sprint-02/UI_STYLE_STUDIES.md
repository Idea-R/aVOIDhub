## Working recommendation

Use the pulp language for moment-to-moment play, combat feedback, crew portraits, event cards, and car management. Use the silhouette language for the world map's environmental layer, title and loading screens, region transitions, journey summaries, and endings. This hybrid keeps systemic information expressive while preserving the second direction's sense of distance and melancholy.
